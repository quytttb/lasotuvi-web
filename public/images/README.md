# Home chart image

`hero-chart.webp` is a screenshot of this application's `ChartBoard`, rendered locally using
`src/test/fixtures/sample-chart.json` with the display name changed to **Lá số minh họa**.
The fixture is fictional test data; the image contains no user's birth information and was
created without calling the live API. The Home page explicitly labels it as sample data.

The image is 1440 × 881, WebP, approximately 94 KiB. Next.js serves appropriately sized variants.
